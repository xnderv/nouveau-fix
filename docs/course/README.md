# Курс: как устроена видеокарта — от транзистора до нейросетей и драйвера (16.11.2026)

Сквозной вопрос: как чип превращает электричество и такт в вычисления и кто этим управляет. Каждая тема заканчивается тем,
как это видно на нашей карте (GTX 560 Ti, GF114). Формат — интервью; в конце темы вопросы на проверку и конспект в этой папке.

через физику и графики.
