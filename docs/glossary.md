# Словарь сокращений проекта

Где расшифровка не опубликована (NVIDIA её не раскрывала, а в nouveau и envytools дано только название), так и сказано.

## Видеокарта и её блоки

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| GPU | Graphics Processing Unit | графический процессор, видеочип |
| GF114 | (кодовое имя NVIDIA: G — GPU, F — Fermi) | наш чип, GeForce GTX 560 Ti |
| Fermi | (название архитектуры, не сокращение) | поколение видеокарт NVIDIA 2010–2012 гг. |
| GPC | Graphics Processing Cluster | кластер вычислительных ядер (шейдеров); у нас — их такт: 101 / 810 / 1800 МГц |
| ROP | Raster Operations Pipeline | блок, который записывает готовые пиксели в память |
| GR, PGRAPH | Graphics (engine) | графический движок; «GR 230‰» — насколько он занят |
| FIFO, PFIFO | First In, First Out | очередь команд от программ к видеокарте |
| PMU | Power Management Unit | встроенный микроконтроллер управления питанием; в нём наш учёт загрузки и скрипты памяти |
| Falcon | FAst Logic CONtroller | тип встроенных микроконтроллеров NVIDIA (PMU — один из них) |
| PTHERM | (P — приставка NVIDIA для блоков, расшифровки нет) + Thermal | тепловой блок: датчик, пороги, замедление |
| PTIMER | (P…) Timer | таймер видеокарты, по нему меряем микросекунды |
| PDISP | (P…) Display | блок вывода изображения |
| FB | FrameBuffer | контроллер видеопамяти (в nouveau — подсистема «fb») |
| PRIV | Privileged (ring) | внутренняя шина регистров видеокарты; «PRIV error» — регистр не ответил |
| hubk01/06/07 | (имена nouveau по номеру домена) | служебные домены тактирования «hub» |

## Частоты и тактирование

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| PLL | Phase-Locked Loop | генератор частоты с фазовой автоподстройкой (ФАПЧ): умножает опорную частоту; ядро на 0f работает от PLL (1800 МГц) |
| VCO | Voltage-Controlled Oscillator | генератор, управляемый напряжением, — «сердце» PLL |
| SPPLL | (так в nouveau; расшифровки нет) | два общих опорных генератора (0xe800, 0xe820), у нас 1620 МГц |
| MPLL | Memory PLL | генератор такта памяти |
| MUX | Multiplexer | переключатель источника такта: PLL или делитель (регистр 0x137100) |
| FSRM | (так в nouveau/envytools; расшифровки нет) | аппаратное замедление такта; наша «скобка» включает его на время переключения источника |
| VID | Voltage IDentification | код напряжения ядра для регулятора (0,95 / 1,075 В) |
| 03 / 07 / 0f | (номера уровней в таблице VBIOS) | уровни производительности: покой / рабочий стол / 3D |

## Температура и вентилятор

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| PWM, ШИМ | Pulse-Width Modulation / широтно-импульсная модуляция | управление вентилятором скважностью импульсов (0xe114 — период, 0xe118 — скважность) |
| GPIO | General-Purpose Input/Output | линии общего назначения: вентилятор (16), тахометр (8), напряжение памяти (23) |
| hwmon | Hardware Monitoring | подсистема Linux для датчиков: `/sys/class/hwmon` (температура, `pwm1`) |
| T2, CRIT | Threshold 2, Critical | аппаратные пороги платы: 102 °C — замедление, 104 °C — сильное замедление |

## Память

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| GDDR5 | Graphics Double Data Rate 5 | тип видеопамяти; 2004 МГц = 4 ГТ/с на ногу |
| MR0…MR7 | Mode Registers | регистры режима микросхем памяти (задержки, напряжение) |
| CL, CWL | CAS Latency, CAS Write Latency | задержки чтения и записи памяти в тактах |
| ODT | On-Die Termination | согласующие резисторы внутри микросхем памяти |
| FBVDDQ | FrameBuffer VDDQ | напряжение ввода-вывода видеопамяти |

## VBIOS и таблицы

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| BIOS | Basic Input/Output System | встроенная программа запуска |
| VBIOS | Video BIOS | прошивка видеокарты: таблицы уровней, памяти, порогов |
| BIT | BIOS Information Table | оглавление таблиц VBIOS (таблица «P» — уровни производительности) |
| DCB | Device Control Block | таблица VBIOS с выходами и линиями GPIO |
| devinit | Device Initialization | скрипты VBIOS, которые настраивают карту при включении |

## Вывод изображения

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| HDMI | High-Definition Multimedia Interface | разъём монитора; 2560×1440 при 60 Гц = 241,5 МГц (`nouveau.hdmimhz=297`) |
| EDID | Extended Display Identification Data | данные, которые монитор сообщает о себе (модель, режимы) |
| SCDC | Status and Control Data Channel | служебный канал HDMI 2.0 (нужен выше 340 МГц) — патч 0003 |
| AVI InfoFrame, ITC | Auxiliary Video Information; IT Content | служебный кадр HDMI о видеорежиме и флаг «компьютерное содержимое» — патч 0005 |
| OLED | Organic Light-Emitting Diode | тип экрана монитора |

## Linux, драйвер, загрузка

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| nouveau | (фр. «новый»; не сокращение) | открытый драйвер видеокарт NVIDIA в ядре Linux |
| nvkm | NVidia Kernel Module (ядро nouveau) | внутренняя часть nouveau, работающая с железом |
| DRM | Direct Rendering Manager | подсистема графики в ядре Linux |
| KMS | Kernel Mode Setting | установка видеорежима ядром |
| MMIO | Memory-Mapped I/O | регистры видеокарты, доступные как память |
| mmiotrace | MMIO trace | запись всех обращений драйвера NVIDIA к регистрам — главный источник наших знаний |
| BAR0 | Base Address Register 0 | окно регистров видеокарты в памяти компьютера |
| PCIe | PCI Express (Peripheral Component Interconnect Express) | шина видеокарты; 2,5 / 5 ГТ/с |
| DKMS | Dynamic Kernel Module Support | пересборка модуля под каждое новое ядро (стабильная версия) |
| GRUB | GRand Unified Bootloader | загрузчик с меню при старте |
| initramfs, initrd | initial RAM filesystem / disk | маленький образ, который GRUB грузит вместе с ядром; nouveau поднимается из него |
| dracut | (название программы) | собирает initramfs на этой системе |
| SysRq | System Request | клавиша аварийных команд ядра (S, U, B — сохранить, отмонтировать, перезагрузить) |
| BPF, bpftrace | Berkeley Packet Filter | механизм ядра для безопасных проб; bpftrace — язык для них (fantrace.bt) |

## Отправка патчей в ядро

| Сокращение | По-английски | Что это у нас |
|---|---|---|
| upstream | (англ. «вверх по течению») | основное ядро Linux, куда отправляем исправления |
| LKML | Linux Kernel Mailing List | главная рассылка ядра (linux-kernel@vger.kernel.org) |
| dri-devel | Direct Rendering Infrastructure — development | рассылка разработчиков графики в ядре |
| lore | (название архива) | lore.kernel.org — архив всех писем рассылок |
| SoB | Signed-off-by | подпись автора под патчем: «я отвечаю за этот код» |
| DCO | Developer's Certificate of Origin | правила, которые автор подтверждает подписью SoB |
| Fixes | (тег) | ссылка на коммит, в котором появилась исправляемая ошибка |
| v2 | version 2 | вторая версия патча после замечаний |
