## Что ищем: «тихие» зависания
Три случая: 21.10 18:16 (ядро живо, SysRq работал, PCIe не переключался); 22.10 ~15:10 и 15:35 (оба после
включения переключения PCIe в 13:04). Для 15:35 есть дамп `results/crash/dmesg-ramoops-20261022-1536.txt`:
`WARNING nvkm_intr: чтение регистра = 0xffffffff` (карта пропала с шины PCIe) → `base-0: timeout` → Machine Check →
hard lockup. Все три — во время снимков экрана (PrtSc) при тесте шрифтов (большой поток по PCIe + смена уровня).

Гипотеза: nouveau переобучает линию PCIe (0x2241c + cfg 0x460) так же, как NVIDIA, но НЕ делает записи NVIDIA
до/после (cfg 0x150, 0x190×4, 0x4b8, сброс флага ошибки cfg 0x80 бит 16, таймеры cfg 0x644/0x650 под скорость,
0x22680). Без них линия на 5 GT/s падает под нагрузкой. В лабораторном драйвере `lab_pcie`:
0 — не трогать; 1 — nouveau переключает при смене уровня; 2 — один раз 5 GT/s; **3 — последовательность NVIDIA**.

## Опыты (по одному, с чёрным ящиком; пользователь во время опыта жмёт PrtSc несколько раз)
A. `bash lab/pcistress.sh 1 10` — ожидаем падение (цель — поймать его дампом). После Reset: `bash lab/blackbox.sh show`.
B. `bash lab/pcistress.sh 3 10` — последовательность NVIDIA; если держится — решение.
C. (если B упал) `bash lab/pcistress.sh 2 10`.
Скрипт сам возвращает `lab_pcie=0` в конце. Итог: значение в `daily/gpu-autoclock.py` PARAMS (`lab_pcie`), затем
в стабильный драйвер (`patches/0010`, clk/base.c: заменить `nvkm_pcie_set_link` на последовательность NVIDIA или
убрать), пересобрать (`stable/stable.sh install`), документировать в `docs/2026-10-22/review-driver.md`.

## sudo из Claude Code
Команды выполняются без интерактивного терминала, пароль ввести некуда. Решение (один раз, пароль вводит пользователь
в панели терминала приложения, Ctrl+`):
```bash
echo 'Defaults timestamp_type=global' | sudo tee /etc/sudoers.d/timestamp-global && sudo chmod 440 /etc/sudoers.d/timestamp-global
```
Дальше перед командами с sudo пользователь делает в терминале `sudo -v` (действует 15 минут). Пароль никогда не
вводится в чат и не сохраняется.
