# Покрытие модели: что NVIDIA пишет при смене уровня и что из этого мы повторяем и понимаем

Файл собирает `lab/coverage.py report` из `registers.tsv` (статусы, руками) и `try7-transitions.json` (выборка из записи
NVIDIA). Не править руками. Как читать — в начале `lab/coverage.py`.

**Регистров в модели: 156** (всего 187, служебных 31): записи хоста при переходах — 112, внутри скриптов памяти и списков — 87, в обоих — 12.

## Откуда берётся значение (переносимость на другие платы семейства)

Колонка «значение» в registers.tsv: таблица — поле таблицы VBIOS; формула — считается из таблиц VBIOS; ремешок — devinit VBIOS по
ремешку памяти; семейство — одно у всех плат семейства (корпус 28.10, вторая карта); чип — одно у всех плат чипа; драйвер —
константа драйвера, в VBIOS нет (нужна таблица по чипам в драйвере); неизвестно — вывести пока не умеем.

| Откуда | Регистров | Доля |
|---|---|---|
| таблица | 4 | 3 % |
| формула | 50 | 32 % |
| ремешок | 6 | 4 % |
| семейство | 47 | 30 % |
| чип | 5 | 3 % |
| драйвер | 23 | 15 % |
| неизвестно | 21 | 13 % |
