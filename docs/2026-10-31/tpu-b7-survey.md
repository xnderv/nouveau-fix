# Выборка TechPowerUp В7 (104 образа, чипы Fermi без записей у нас) через генератор ядра — 31.10.2026 (класс В)

Взято 30.10 под вопрос «покрывают ли правила генератора все платы этих чипов» (provenance.md, В7), разобрано только сейчас.
Метод: `lab/core-predict.py predict ОБРАЗ --flag` по каждому образу (правила П12–П14), сравнение получившейся частоты узла с
частотой таблицы уровней. Записей NVIDIA для этих плат нет — это проверка «что сделает генератор», не «как NVIDIA».

**Разбор:** 104 из 104 образов (GF100 20, GF110 20, GF104 20, GF108 ~22 вместе с Quadro 600, GF119 22) — без ошибок.
Отклонение от таблицы ≤ 3 МГц у всех узлов, кроме трёх случаев:

| случай | платы | что даёт генератор | проверено записью NVIDIA? |
|---|---|---|---|
| GF108, hubk01 на 0f, флаг 2, 1400 МГц | 11 | делитель 1620 (+16 %): у hubk01 нет основного делителя, 1400 из 1620 не получить | нет (есть только 1595 → 1620, одна плата в базе) |
| GF108, hubk01 на 0f, флаг 2, 1595 МГц | 5 | делитель 1620 (+2 %) | да: так делает NVIDIA (db-core-check.md) |
| Quadro 600 (10de:0df8) и одна GF108: hubk01 на 0f с флагом 1, у hubk06 другая частота (1280 против 1012; 1595 против 1282) | 6 | hubk01 едет на PLL hubk06 → частота hubk06 (−20 %) | нет |
| GF119, ROP на 0f, флаг 0, 1701 МГц | 22 | делитель 1620 (−5 %): своей PLL у ROP на GF119 нет (в записях переключатель 0x185 — бит ROP не ставится) | частично: путь «делитель» — да; частоту NVIDIA у ROP GF119 не сверяли |
| мелкие (GF100, GF104, GF110 ROP/hubk07/GPC на PLL) | 7 | сетка PLL, ≤ 0,5 % | да (так же, как у NVIDIA) |

**Что это значит.** Для двух наших тестировщиков (GF106, GF114) ни один случай не встречается. Для генератора «на все Fermi»
это белые пятна: что NVIDIA делает с hubk01, когда таблица просит частоту, которой его источник не даёт (1400 с делителя;
1280 при hubk06 на 1012). Образы VBIOS этого не покажут — нужны записи NVIDIA с таких плат: GF108 (GT 430/440/530) с hubk01 1400
и Quadro 600. Сначала — проверить, есть ли такие платы в базе трасс nouveau (по 0x020130/таблицам их образов).

**Нужно ли докачивать с TechPowerUp.** Для правил ядра — нет: образы дают только такую статическую проверку, и на 9 чипах Fermi
(410 образов) она уже показала, где пятна. Новые вопросы закрываются записями, а не образами. В8 (предшественники: Tesla,
GeForce 6/7) — только для вопроса «как развивались таблицы VBIOS» (evolution.md), генератору Fermi не нужна. Ноутбучных VBIOS
на TechPowerUp почти нет (GF117M Acer не нашли — пришли GF119 и GK208).
