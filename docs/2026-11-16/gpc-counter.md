# Счётчик тактов GPC на Fermi (16.11.2026, класс Г + Б)

**Источник адресов:** открытый код NVIDIA для Tegra (nvgpu, hw_trim_gk20a.h / hw_trim_gm20b.h):
`trim_gpc_clk_cntr_ncgpcclk_cfg` = 0x134124 + i·0x200 (N тактов опоры — биты 0–13, write_en 0x10000, enable 0x100000,
reset 0x1000000), `_cnt` = 0x134128 + i·0x200 (биты 0–19). Порядок замера — clk_gm20b.c (get_gpcclk_clk_measure); NVIDIA
перед замером выключает замедление («Disable clock slowdown during measurements») — значит, счётчик видит замедленный такт.
envytools для Fermi эту область не описывает.

**Проверка на GF114** (build-1116 — только чтение при загрузке; build-1116b, srcversion 71BF52FD — ключ `lab_cntr_n`, замер
после каждой смены уровня; 16.11 15:30, N = 2700):

| уровень | узел GPC2CLK по драйверу | отсчёт (оба GPC) | при опоре 27 МГц | отношение к GPC2CLK/2 |
|---|---|---|---|---|
| 0f | 1 800 000 кГц | 90 133 / 90 134 | 901,3 МГц | 1,0015 |
| 07 | 810 000 кГц | 40 560 | 405,6 МГц | 1,0015 |
| 03 | 101 250 кГц | 5 070 | 50,7 МГц | 1,0015 |

**Вывод:** счётчик на GF114 есть, по тем же адресам и с тем же форматом, что у Kepler/Maxwell-Tegra. Опора — 27 МГц (кварц).
Считает **GPCCLK = GPC2CLK / 2** (900 при «шейдерных» 1800), по обоим GPC одинаково. Постоянный избыток 0,15 % на всех уровнях —
окно счёта примерно на 4 такта опоры длиннее N (свойство счётчика, не частоты). Два чтения через 100 мкс совпадают — счёт
заканчивается сам. При загрузке до любого замера cnt = 0x000ffbfc, cfg = 0.

**Зачем:** окно счёта отсчитывается по часам карты с момента, когда запись включения дошла до неё, — независимо от времени
процессора и задержек PCIe. Это даёт способ увидеть, когда замедление в скобке реально снижает такт, без регистра статуса
0x0201e0 (опыт ещё не делался).
