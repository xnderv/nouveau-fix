**Что мы узнали благодаря твоей записи NVIDIA.** Пауза, которую драйвер NVIDIA выдерживает перед каждым переключением такта, —
не константа драйвера. Он считает её из регистра, который пишет VBIOS платы при включении. Мы это проверили на своей карте:
подменяли значение регистра перед загрузкой NVIDIA — пауза менялась. Для твоей GF106 расчёт даёт 18,96 мкс, в твоей записи
17–21 мкс. Сейчас у тебя стоит «ждать аппаратный признак плюс 16 мкс», то есть примерно столько же — менять ничего не нужно.
