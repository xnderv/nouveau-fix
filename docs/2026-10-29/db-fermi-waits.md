# Ожидание NVIDIA в скобке FSRM по чипам Fermi: трассы из internal vbios repo nouveau — 29.10.2026 (класс Д)
Источник: закрытый репозиторий VBIOS и трасс проекта nouveau («internal vbios repo»), доступ — Martin Roukala; использовать данные разрешено (29.10), письма участников не читаются и не публикуются, участники обезличены.
Метод: lab/db-fermi-wait.sh + trace/trace-dwell-bound.py (порог по показаниям PTIMER: (предпоследнее, последнее]).
Трассы с крупным шагом цикла (2 чтения таймера, шаг 25–50 мкс из-за накладных mmiotrace) дают только «ожидание есть».

## Когда что появилось (по трассам с известной версией драйвера)
| версия | дата | чип | скобка FSRM | ожидание по таймеру |
|---|---|---|---|---|
| 260.19.12 | 10.2010 | GF106 | **нет** (43 переключения 0x137100, ни одной записи 0x0201a0) | — |
| 270.30 | 02.2011 | GF104 | есть | нет |
| 270.41.06 | 04.2011 | GF114 (наш стенд) | есть | нет |
| 285.05.09 | 09.2011 | GF114M (1211) | 2 входа, переходов в записи нет | не видно |
| 304.60 | 10.2012 | GF104 | есть (21) | **есть** |
| 390.157 | 2017–2022 | GF114, GF106 | есть | есть |
Итог: скобку NVIDIA добавила между 260.19 и 270.30 (в 270.41.06 — «исправлены зависания при запуске X, чаще GF104/GF106»),
ожидание в скобке — между 270.41.06 и 304.60 (точнее 285–304 не сужено).
Порог разный по чипам и совпадает с группами 0x020130: 040a (GF110/GF114) → 8 мкс GPC; 030a (GF104/GF106/GF116) → ~18 мкс;
060c (GF108/GF117/GF119-1056) → ~150 мкс. GF110 1080 (2016) — 4–5 мкс у GPC: другая версия драйвера или плата (не ясно).

## 0x020130 по платам (devinit VBIOS из базы) — группы совпадают с «настольная / мобильная»
- 8107040a — GF110 (1080/1081/1086), GF114 (1200/1201/1205);
- 8107030a — настольные GF104 (0e22), GF106 (0dc4, 0dd8), GF108 (0de0/0de1/0f01/0f02);
- 8107060c — мобильные: GF108M (0df0, 0df4, 0dfc, 0de9), GF106M (0dd2), GF114M (1211), GF119M (1056).
Порог ожидания по группам: 040a — 8 мкс GPC (при /6) и 4–5 мкс (при /2); 030a — ~18 мкс (GF106); 060c — ~150 мкс (измерен на
мобильных GF108M 0de9 и 0df4). Одна микросхема в разных группах (GF108 0de1 против 0df4, GF114 1200 против 1211) — довод, что
ожидание связано с платой через VBIOS (0x020130), а не только с чипом; решающая проверка — опыт Е17.
VBIOS всех GF110 пишут одинаково (0x020160 = 0x20000, 0x020164 = 0x20082), так что разница /6 и /2 между 1086 и 1080 — не из
этих полей (версия драйвера или другое поле VBIOS).
