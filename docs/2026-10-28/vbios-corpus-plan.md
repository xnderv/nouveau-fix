# Корпус VBIOS с TechPowerUp: план работы (28.10.2026)

## 0. Рамки разрешения
Письмо W1zzard (главный редактор TechPowerUp) от 28.10: присланными файлами (328 образов GTX 560 Ti, скачанных 24.10)
пользоваться можно; дальше — **небольшие целевые подмножества** базы для исследования, **не вся база**; если найдём значение,
которое стоит показывать в разборе на странице VBIOS, — сообщить им. robots.txt сайта по-прежнему запрещает автоматический
доступ без письменного разрешения и закрывает коллекцию для агентов Claude; разрешение выдано автору проекта, поэтому
выгрузку запускает он сам (`tools/tpu-vbios-fetch.py`), скрипт представляется честно (имя проекта, ссылка, дата
разрешения), один поток, пауза 3 с, остановка при 403/429. Образы 24.10 физически утрачены (удалены по решению 24.10), так
что первая выборка — та же: **GTX 560 Ti** (это и есть «те файлы»). Каждая следующая выборка — только под конкретный
вопрос, с записью здесь и в `docs/provenance.md`: что взято, сколько, зачем. Образы лежат вне репозитория
(`~/Home/nouveau-archive/tpu-vbios/<дата>-<модель>/` + manifest.csv с SHA256); в репозиторий идут только разборы (числа,
таблицы), с пометкой «TechPowerUp, по разрешению 28.10» (класс В).

## 2. Порядок
1. Выгрузка GTX 560 Ti (ожидаемо ~330 образов, ~30 минут при паузе 3 с): `python3 -I tools/tpu-vbios-fetch.py
   ~/Home/nouveau-archive/tpu-vbios/2026-10-28-gtx560ti --model "GTX 560 Ti"`. Запускает автор. Manifest — источник
   истины: id, slug, URL, SHA256, размер, дата.
2. Проверка корпуса: все ли образы — GF114 (PCI id, строка чипа), дубликаты по SHA256, битые образы; таблица «вендор /
   ревизия / дата VBIOS / версия 70.24.xx».
3. Разбор существующими инструментами: `lab/vbios-survey.py` → survey.json + CSV; `lab/vbios-stats.py` — статистика
   уровней, таймингов, ramcfg (В1, В4, В5).
4. Новое: разбор devinit (скрипты init BIT 'I') — список записей регистров с адресами и значениями по каждому образу;
   сводка «регистр → множество значений по корпусу» для диапазонов PTHERM, PCLOCK, 0x132000 (В2, В3). Сверка с тем, что
   NVIDIA 390/270 пишут на старте (init-270.26-vs-270.41.06, init 390).
5. Отчёт `docs/2026-10-28/vbios-corpus.md`: по каждому вопросу — таблица, вывод, класс В; что оказалось константой чипа,
   что значением платы, что нашей особенностью. Обновить учебник (П-правила) и карту ядра. Сообщить TechPowerUp, если
   найдём поле, которого нет в их разборе (их просьба).
6. Только после отчёта решать про В6 (вторая узкая выборка).

## 3. Чего не делаем
Не качаем «всё»; не публикуем образы и не кладём их в репозиторий; не используем чужие разборы VBIOS, основанные на
декомпиляции драйвера (правило происхождения); не ходим на сайт агентами Claude.
