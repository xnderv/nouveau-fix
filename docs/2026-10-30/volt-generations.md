# Формула напряжения nouveau по поколениям — 30.10.2026

Вопрос: расчёт напряжения nouveau (карта напряжений VBIOS + метка качества чипа, nvkm_volt_map, затем ступень регулятора не
ниже расчётной, nvkm_volt_set) — та ли это формула, что у NVIDIA, и сколько поколений она живёт. Класс Г (код nouveau),
В (VBIOS), Д (записи internal vbios repo). Инструменты: `lab/db-core-check.py` (Fermi, VID), `lab/db-volt-gen.py` (ШИМ,
Kepler и новее). Сырые данные — вне репозитория.

## Формат карты напряжений по поколениям (все образы VBIOS базы)
| поколение | карта напряжений | смысл |
|---|---|---|
| NV4x, Tesla G8x/G9x, GT2xx | нет ни в одном образе (BIT P версии 1 или 2 без указателя) | напряжение уровня — число из таблицы, формулы нет |
| Fermi | 0x10 — 69 образов; 0x20 — 3 поздних | три коэффициента: a0 + a1·s + a2·s² (s — метка качества) |
| Kepler | 0x20: режим 0 (та же формула), режим 1 (шесть коэффициентов, есть температура), изредка 2; записи связываются (link — сумма двух записей) | |
| Maxwell | 0x20: режимы 0, 1, 3 (3 — середина между пределами) | |
| Pascal и новее | новый формат 0x30 | nouveau его не разбирает; напряжением там управляет подписанная прошивка |

## Совпадение с NVIDIA
- **Fermi, регулятор VID:** у всех 57 пар «плата — уровень» точное совпадение ступени; из них 15 плат с уровнем, где
  напряжение считается по метке качества (1396…1614), и почти везде расчёт падает между ступенями — округление вверх
  каждый раз даёт ступень NVIDIA (db-core-check.md).
- **Kepler и Maxwell, регулятор ШИМ** (12 плат: GK104, GK106, GK107, GK208, GM107, GM108, GM204; метка качества — фьюз
  0x3a8): 72 различных напряжения NVIDIA. 60 объясняются расчётом nouveau до шага ШИМ при 50 °C. Остальные 12 — верхние
  уровни, где запись карты связана с записью режима 1 (с температурой): каждое объясняется той же записью при 30–60 °C.
  Температуру читает только 1 запись из 76 (45–46 °C) — у неё совпадение начинается с 47 °C. Делитель ШИМ у NVIDIA во всех
  случаях равен расчёту nouveau (27 648 000 / частота ШИМ из VBIOS).
- **Не видно:** в части записей Kepler и Maxwell и во всех записях Pascal (GP10x) хост напряжение не пишет — его ставит
  прошивка; у плат Kepler с регулятором VID записей VID в записи нет. У ноутбучных Fermi (GF108, GF117, GF119) с ШИМ — не
  разобрано; nouveau для Fermi ШИМ-напряжение не поддерживает вовсе (gf100/gf117 — только VID).

## Вывод
Формула одна от Fermi до Maxwell включительно; у Kepler и Maxwell к ней добавлена температурная часть (режим 1) и связи
записей — nouveau их считает. Для Fermi с VID проверено полностью; для Kepler и Maxwell — с оговоркой о температуре.
Открыто: температура в момент установки (нужна запись, где она читается), ШИМ на ноутбучных Fermi.
