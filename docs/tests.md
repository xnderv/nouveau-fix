# Журнал опытов: номер — дата — модуль — скрипт — итог

Две нумерации, не путать:
- **опыт** — сквозной номер (…, 107, 108, …); файл результата `results/testNNN-ДАТА-ВРЕМЯ.txt` (+ `.sum`). Новый прогон —
  новый номер, даже если скрипт старый (так файлы `test100-…` от 21.11 на 1121c и стали опытом 108);
- **сборка модуля** — по дате: `build-MMDDx` (1121c — 21 ноября, третья за день), `lab-vbios-src/build-…/nouveau.ko`. В журнале
  ядра и в первой строке файла результата — отпечаток модуля (srcversion); по нему опыт однозначно связан со сборкой.
