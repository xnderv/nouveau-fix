ЗАПИСЬ ДРАЙВЕРА NVIDIA 390 — ПО ШАГАМ

НОВАЯ ЗАПИСЬ (диск записи уже собран; сценарий версии 7 — без снимков, со сторожем; контроль и запись за один запуск, 24.10)

0. Выключить компьютер, подключить диск Seagate ST120FN0 (горячее подключение этого порта в BIOS выключено),
   включить и загрузиться как обычно, в основную Ubuntu.

1. Скопировать новый сценарий на диск записи (в основной системе; старые скрипты с диска сохранятся в архив):
   sudo ~/Home/nouveau-fix/trace/update-trace-disk.sh

2. Перезагрузка. На экране с логотипом Gigabyte — F12 (меню загрузки), выбрать ST120FN0 (Seagate 120 ГБ).
   Без меню грузится обычная Ubuntu.

3. В системе записи (чёрный экран с текстом, вход сам, английская раскладка, ~ = Shift+Ё):
   sudo ~/trace/run-trace.sh
   Ничего не трогать ~9 минут, клавиши не нажимать. Два прохода одного сценария подряд: контроль без записи (~3,5 мин),
   потом драйвер выгружается и всё повторяется под записью (~4–5 мин); между проходами на секунды — текстовый экран.
   ИНДИКАТОРЫ: Scroll Lock мигает всё время — система жива; маленькие шестерёнки крутятся всё время — жива карта/X.
   Большие шестерёнки то появляются, то исчезают — так задумано.
   СТОРОЖ: если драйвер NVIDIA сообщит об отвале карты или 2 минуты не будет продвижения, скрипт сам сохранит журналы и
   ВЫКЛЮЧИТ машину (не перезагрузит: после зависшей карты тёплый сброс дважды давал пустой список дисков). Тогда — просто
   включить, без F12 (загрузится обычная Ubuntu), и написать мне.
   Reset — только если и Scroll Lock перестал мигать больше чем на минуту. Конец — строка «ГОТОВО. Результат: …».

4. Обратно: sudo reboot  (без меню загрузится обычная Ubuntu)

5. Забрать запись (в основной системе):
   sudo mkdir -p /mnt/u2204-trace && sudo mount -o ro LABEL=u2204-trace /mnt/u2204-trace && mkdir -p ~/Home/nouveau-fix/results/trace-try3 && cp -r /mnt/u2204-trace/home/*/trace/out-* ~/Home/nouveau-fix/results/trace-try3/ && sudo umount /mnt/u2204-trace && ls -lhR ~/Home/nouveau-fix/results/trace-try3

СБОРКА ДИСКА С НУЛЯ (делалась 20.10, повторять не нужно)
   sudo apt install -y debootstrap && chmod +x ~/Home/nouveau-fix/trace/*.sh && sudo ~/Home/nouveau-fix/trace/build-trace-disk.sh
   На вопрос напиши СТЕРЕТЬ. Ждать 20–30 минут до «Готово».
