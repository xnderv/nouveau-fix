ЗАПИСЬ ДРАЙВЕРА NVIDIA 390 — ПО ШАГАМ

1. Установка (в основной системе):
   sudo apt install -y debootstrap && chmod +x ~/Home/nouveau-fix/trace/*.sh && sudo ~/Home/nouveau-fix/trace/build-trace-disk.sh
   На вопрос напиши СТЕРЕТЬ. Ждать 20–30 минут до «Готово».

2. Перезагрузка. На экране с логотипом платы — клавиша меню загрузки (ASUS F8, Gigabyte F12, MSI F11).
   Выбрать ST120FN0 (Seagate 120 ГБ). Без меню грузится обычная Ubuntu.

3. В новой системе (чёрный экран с текстом, вход сам, английская раскладка, ~ = Shift+Ё):
   sudo ~/trace/run-trace.sh
   Ничего не трогать ~6 минут. Конец — строка «ГОТОВО. Результат: …».
   Если завис больше 10 минут: Ctrl+Alt+F1, если не помогло — Reset.

4. Обратно: sudo reboot  (без меню загрузится обычная Ubuntu)

5. Забрать запись (в основной системе):
   sudo mkdir -p /mnt/u2204-trace && sudo mount -o ro LABEL=u2204-trace /mnt/u2204-trace && mkdir -p ~/Home/nouveau-fix/results/trace-nvidia && cp -r /mnt/u2204-trace/home/user/trace/out-* ~/Home/nouveau-fix/results/trace-nvidia/ && sudo umount /mnt/u2204-trace && ls -lhR ~/Home/nouveau-fix/results/trace-nvidia
