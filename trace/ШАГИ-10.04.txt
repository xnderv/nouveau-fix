ЗАПИСЬ ПЕРВЫХ ДРАЙВЕРОВ NVIDIA (270.26 и 270.41.06) В UBUNTU 10.04 — ПО ШАГАМ (26.10, вторая версия: меню на цифрах)

Зачем: 270.26 — первый драйвер с поддержкой GTX 560 Ti (15.02.2011); в 270.41.06 NVIDIA исправила «карта перестаёт
отвечать при запуске X» (чаще на GF104/GF106). Сценарий записи тот же, что у записи 390.157 (прогон 7, try7).
10.04 стоит на втором разделе диска Seagate ST120FN0 рядом с 22.04; сети в ней нет.
В 10.04 ничего набирать не нужно: после входа сразу меню, всё — одной цифрой. Текст на экране там латиницей.

0. В ОСНОВНОЙ системе (после каждой правки скриптов): пункт меню загрузки и файлы на диск 10.04
     sudo ~/Home/nouveau-fix/trace/lucid-boot-entries.sh
     sudo ~/Home/nouveau-fix/trace/lucid-disk.sh put

1. Перезагрузка, на логотипе Gigabyte — F12, выбрать ST120FN0. Через 5 секунд сама грузится 10.04
   (22.04 — стрелкой вверх). Появится меню стенда:
     1  Install driver 270.26        2  Install driver 270.41.06
     3  RECORD (~9 min)              4  Reboot        5  Power off        0  Command line

2. Запись 270.26 (драйвер 270.26 уже установлен 26.10, карта после загрузки чистая): нажать 3.
   ~9 минут ничего не трогать: контроль без записи, потом запись. Видно X с шестерёнками; между проходами — строки >>>.
   Конец — «DONE. Saved: …», Enter — назад в меню.

3. Драйвер 270.41.06: нажать 2. Установщик NVIDIA спросит: License — Accept (решаешь ты); удалить прежний драйвер — Yes;
   32-bit compatibility libraries — No; run nvidia-xconfig — No.
   Потом 4 (перезагрузка) -> F12 -> ST120FN0 -> меню -> 3 (запись 270.41.06).
   Перезагрузка нужна, чтобы запись начиналась на чистой карте, как в try7; без неё меню запись не даст.

4. Обратно: 4 (перезагрузка) без F12 — загрузится основная Ubuntu. В основной системе забрать записи:
     sudo ~/Home/nouveau-fix/trace/lucid-disk.sh get
   и написать мне.

ЕСЛИ ЧТО-ТО НЕ ТАК (основная система и 22.04 при этом не страдают):
 - СТОРОЖ: если драйвер зависнет (на запуске X — это возможно, ради этого и записываем) или 2 минуты не будет
   продвижения, сценарий сам сохранит журналы и ВЫКЛЮЧИТ машину. Это тоже результат: включить, F12, дальше по шагам;
 - строка «STOP: …» — прочитать, что в ней сказано (обычно «сначала перезагрузись»); непонятно — 4, основная система, мне;
 - загрузка встала («Kernel panic», «(initramfs)», чёрный экран дольше 2 минут) — фото экрана, Reset, без F12
   загрузится основная Ubuntu, написать мне;
 - не работает клавиатура — переткнуть её в чёрный USB-порт (синие USB 3.0 ядро 2010 года может не знать).

ЖУРНАЛЫ: всё лежит в ~/trace/ системы 10.04 — папки out-ВЕРСИЯ-ВРЕМЯ (шаги, журналы ядра и X, запись),
install-ВЕРСИЯ.log; системные журналы — /var/log/syslog и kern.log. Время в 10.04 — UTC (в Москве +3 ч).
lucid-disk.sh get забирает всё это в ~/Home/stand-2011/results/.
